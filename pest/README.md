# Оферта за пест контрол (ДДД) за АВАНТИ — „УНИЩОЖИТЕЛИ“ ЕООД

Втора, напълно отделна оферта, до папката `site/` (ароматизацията). Двете нямат нищо общо и се хостват независимо.

```
index.php            страницата (кинематографична; теми: Ден (основна), Хигиена, Еко, Маслина, Галерия, Нощ, Емблема)
assets/css/           offer.css + offer.min.css (свити с tools/minify.mjs)
assets/js/            three.min.js + app.min.js (общият 3D двигател, но с логика за дератизационни точки)
assets/models/        реалистичните човешки модели (същите като в site/)
assets/fonts/ img/    шрифтове, подпис, логото и емблемата на УНИЩОЖИТЕЛИ (logo.png, emblem.png)
api/sign.php          приема подписа (JSON с PNG) → MySQL + имейл до unishtojiteli@gmail.com
api/schema.sql        таблицата за подписите
.htaccess robots.txt  защита: без индексиране, без листване, само с линк
```

## Какво е различно от ароматизацията
- 3D магазинът и хората са същите, но **дифузерите са заменени с номерирани неотровни дератизационни кутии по пода** (до входа, зад хладилните витрини, към задния вход).
- Камерата слиза на нивото на пода при всяка точка.
- Слоеве: **Зона на контрол** (пръстени по пода) и **Пътища на проникване** (стрелки от входовете към точките).
- Кинематографичен акцент **„UV Обход“**: при влизане прохладна UV светлина, пътищата на проникване засветяват към точките и върху всяка кутия светва златен печат **„КОНТРОЛ“**.
- Цени: дезинсекция (15,00 € + 0,078 €/м², закръглено до 0,50 €) + неотровни точки (5,00 €/обект). Общо **1 443,50 € / месец** за 48 обекта; складовете по оферта.
- Нула препратки към ароматизация или KAYA LUX.

## Локално
Сървърът `tools/serve.py` (в корена на проекта) обслужва двете оферти:
- ароматизация: `http://localhost:5340/`
- пест контрол: `http://localhost:5340/pest/`

## Хостване (cPanel, тайна папка на поддомейн)
Както при `site/` (виж `hosting/`): качва се **съдържанието на `pest/`** в отделна тайна папка (напр. `oferti.<домейн>/<тайно-име>-ddd/`), с `.htaccess` (DirectoryIndex index.php). MySQL: импортирай `api/schema.sql`, попълни константите в `api/sign.php` (DB_* и MAIL_TO = unishtojiteli@gmail.com).

## След промяна в кода
`cd tools && npm i && node minify.mjs` — пресглобява app.min.js и offer.min.css и за двете оферти и сменя ?v= хешовете.
