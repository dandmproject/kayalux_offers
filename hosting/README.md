# Частни оферти на домейна на KAYA LUX

Целта: офертата се отваря само от хората, на които ти дадеш парола. Не се индексира от Google, не се вижда от никой друг, не се кешира по пътя.

## Как работи

Един поддомейн (примерно `oferti.kayalux.bg`) с папка, в която стоят HTML файловете. Папката е заключена с парола на ниво Apache (`.htaccess`). Всеки клиент има свой потребител и своя парола. Отделно сървърът праща заглавка `X-Robots-Tag: noindex`, така че дори някой да сподели линка, търсачките не го индексират.

Basic Auth върху HTTPS е достатъчен за този случай (документ за един адресат, без лични данни, без плащания). По-силна защита (вход с код по имейл, срок на линка) означава сървърна логика, която в cPanel се прави с PHP. Мога да я направя, ако искаш; за момента препоръчвам паролата.

## Стъпки в cPanel

1. **Поддомейн.** cPanel → *Domains* → *Create A New Domain* → `oferti.kayalux.bg`. Document root: `/home/CPANEL_USER/oferti`. (Отделна папка, не `public_html`, за да не наследява нищо от сайта.)

2. **SSL.** cPanel → *SSL/TLS Status* → избери поддомейна → *Run AutoSSL*. Изчакай да стане зелено. Без това паролата пътува некриптирана.

3. **Качване.** cPanel → *File Manager* → отвори `/home/CPANEL_USER/oferti`. Качи:
   - `avanti-2026-148-a.html` (офертата; преименувай я, за да няма нищо познато в името)
   - `.htaccess` от тази папка
   - `robots.txt` от тази папка

   Ако File Manager не показва `.htaccess`: *Settings* (горе вдясно) → *Show Hidden Files*.

4. **Файл с паролите, извън уеб папката.** File Manager → `/home/CPANEL_USER/` (една папка над `oferti`) → *+ File* → `oferti.htpasswd`. Съдържание: по един ред на клиент, генериран така:
   - в cPanel → *Terminal*: `htpasswd -nB avanti` (пита за парола, печата реда)
   - или офлайн на твоя компютър: `htpasswd -nB avanti`
   - ред без парола в чист вид никъде не се записва.

   Пример как изглежда файлът (паролата тук е примерна, не я използвай):
   ```
   avanti:$2y$05$H0mFz9y...
   ```

5. **Път в `.htaccess`.** Отвори `.htaccess` в `oferti` и смени `CPANEL_USER` в реда `AuthUserFile` с истинското си cPanel потребителско име (вижда се горе вдясно в cPanel).

6. **Директорна защита (алтернатива на 4–5).** Ако не искаш да пипаш файла с ръка: cPanel → *Directory Privacy* → избери `oferti` → *Password protect this directory* → добави потребител и парола. cPanel сам създава `.htpasswd` извън уеб папката и добавя редовете в `.htaccess`. Тогава изтрий секция 3 от моя `.htaccess`, за да не се дублира.

7. **Проверка.**
   - Отвори `https://oferti.kayalux.bg/avanti-2026-148-a.html` в частен прозорец: трябва да поиска потребител и парола.
   - `https://oferti.kayalux.bg/` без файл: трябва да върне 403, не списък с файлове.
   - `http://` (без s): трябва да прескочи на `https://`.
   - На https://securityheaders.com въведи адреса: очаквай A/A+.
   - В Google Search Console (ако домейнът е добавен) не подавай sitemap за поддомейна.

## Как даваш достъп

- Един клиент = един потребител в `.htpasswd`. Спираш достъпа, като изтриеш реда му. Действа веднага.
- Пращаш на клиента: адреса, потребителското име и паролата **по два различни канала** (адрес по имейл, парола по телефон/Viber).
- Не слагай линка в социални мрежи, презентации или публични документи.
- Когато офертата изтече, изтрий файла от сървъра. Пазиш копие в това хранилище.

## Какво покрива `.htaccess`

| Мярка | Какво спира |
|---|---|
| `Options -Indexes` | Списък на файлове в папката |
| Basic Auth | Отваряне без парола |
| Redirect към HTTPS + HSTS | Прихващане на паролата по пътя |
| `X-Robots-Tag: noindex` | Индексиране от Google/Bing дори при споделен линк |
| `robots.txt` | Учтивите ботове (вторична защита) |
| `Cache-Control: no-store` | Копие в прокси/CDN кеш |
| `X-Frame-Options: DENY` | Вграждане на офертата в чужд сайт |
| `Referrer-Policy: no-referrer` | Изтичане на адреса към cdnjs при зареждане на three.js |
| CSP | Изпълнение на чужд код в страницата |
| `Require all denied` за `.ht*`, `.log`, `.bak` | Изтегляне на служебни файлове |
| `LimitExcept GET HEAD` | POST/PUT/DELETE заявки |

## Ако хостингът е LiteSpeed (чест случай в cPanel)

Всичко по-горе работи и там. Единствено `Header unset ETag` може да даде предупреждение; ако страницата даде 500, махни този ред.

## Ако някога решиш да свалиш three.js от cdnjs

Офертата зарежда една външна библиотека (three.js). Ако искаш нула външни заявки: свали `three.min.js` в същата папка, смени `src` в HTML файла на `three.min.js` и махни `https://cdnjs.cloudflare.com` от CSP реда.
